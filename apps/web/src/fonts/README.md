# Fontes locais

Inter e Outfit são fontes variáveis obtidas do repositório oficial Google Fonts:

- [Inter](https://github.com/google/fonts/tree/main/ofl/inter), `Inter[opsz,wght].ttf`.
- [Outfit](https://github.com/google/fonts/tree/main/ofl/outfit), `Outfit[wght].ttf`.

Os arquivos são distribuídos sob a SIL Open Font License 1.1; os textos correspondentes estão em `LICENSE-Inter.txt` e `LICENSE-Outfit.txt`. O layout usa `next/font/local`, mantendo as mesmas famílias sem baixar fontes durante o build.
